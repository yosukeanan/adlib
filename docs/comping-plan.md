# コンピング練習モード

> 最新の計画は [roadmap.md](roadmap.md) を参照。この文書は経緯と詳細の記録。

作成日：2026-10-07

## 目的

ソロ（単音のアドリブ）に加えて、コンピング（伴奏）を練習できるようにする。まずは既存アプリと機能面で同じ水準にする。

## フェーズA（実装済み）

- 練習画面で「ソロ／コンピング」を切り替える。コンピングではピアノが止まり、ベースとドラムだけになる。
- **シェル（3音）**：テンプレート4種。
  - 6弦ルート：R-7-3（`8x99xx`）、R-3-7（`879xxx`）
  - 5弦ルート：R-3-7（`x324xx`）、R-7-3（`x3x45x`）
  - m7♭5は3rdの代わりに♭5を使う（`787xxx`、`x343xx`）。5弦ルートのR-7-3型は5フレットの広がりになるため生成しない。
  - 7altはR-3-♭7（オルタードのテンションは入れない）。
- **ボイスリーディング**：コーラス全体について、動的計画法で手の移動量と選んだポジションからの距離の合計を最小にする。「自動」は6弦ルート・5弦ルートを両方使い、どちらかに固定した場合よりコストが大きくならない（テストで確認）。
  - コードによっては、選んだポジションの中にシェルが存在しない（例：5〜9フレットのG7。ルートは3フレットか10フレット）。その場合は最も近い形を選び、範囲外の音は指板に表示されない。
- **リズム**：フォー・ビート、2・4拍、チャールストン、逆チャールストン、先取り（4拍目の裏で次のコード）。1小節8マスの段で、打つ位置と今の拍を示す。
- **お手本**：シェルをリズムどおりに鳴らす。
- コンピング中は単音のマイク判定を止める（和音には向かないため）。

## フェーズB（未着手）：マイクで和音を判定

- FFTからクロマ（12音名ごとの強さ）を求め、今のシェルの3音がそろっているかを見る。オクターブ違いと余分な音は許容する（Chord Trainerと同じ考え方）。
- 正解するまで次のコードへ進まない「待ちモード」（テンポなし）を作る。
- **リスク**：和音の検出精度は未知数。先に実機で、ギターの和音からクロマで3音を拾えるかを試してから作り込む。

## フェーズC（未着手）：差別化

- 弾いたタイミングと、選んだリズムパターンとのずれを判定して統計にし、練習の提案につなげる。

## その他の候補
